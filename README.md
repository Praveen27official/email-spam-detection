# 📧 Email Spam Detection using Machine Learning

## 🚀 Overview
This project builds a machine learning model to classify emails as **Spam** or **Not Spam (Ham)** using Natural Language Processing (NLP).

---

## 📊 Dataset
- Contains labeled messages:
  - spam
  - ham
- Features:
  - Message text
  - Label

---

## 🧠 ML Techniques Used
- Text Preprocessing (NLP)
- TF-IDF Vectorization
- Naive Bayes Classifier

---

## 📈 Results
- High accuracy on classification
- Efficient detection of spam messages
